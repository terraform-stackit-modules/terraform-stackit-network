# terraform-stackit-network

Terraform module to create a [STACKIT](https://www.stackit.de/en/) network, with optional security group and rules.

Designed for use with STACKIT virtual machines and managed databases.

<!-- markdownlint-disable MD001 -->
## Usage

### Network only

```hcl
module "network" {
  source  = "terraform-stackit-modules/network/stackit"

  project_id  = "<project_id>"
  name        = "my-network"
  ipv4_prefix = "192.168.0.0/24"
}
```

### Network with security group

```hcl
module "network" {
  source  = "terraform-stackit-modules/network/stackit"

  project_id  = "<project_id>"
  name        = "my-network"
  ipv4_prefix = "10.0.1.0/24"

  create_security_group      = true
  security_group_description = "Allow SSH inbound and all TCP egress"

  security_group_rules = [
    {
      direction  = "ingress"
      ether_type = "IPv4"
      ip_range   = "0.0.0.0/0"
      protocol   = { name = "TCP" }
      port_range = { min = 22, max = 22 }
    },
    {
      direction  = "egress"
      ether_type = "IPv4"
      ip_range   = "0.0.0.0/0"
      protocol   = { name = "TCP" }
    },
    # Allow traffic from another security group
    {
      direction                = "ingress"
      ether_type               = "IPv4"
      remote_security_group_id = "<other_security_group_id>"
      protocol                 = { name = "TCP" }
      port_range               = { min = 5432, max = 5432 }
    },
    # Match by protocol number instead of name
    {
      direction  = "egress"
      ether_type = "IPv4"
      ip_range   = "0.0.0.0/0"
      protocol   = { number = 6 }
    },
  ]
}
```
