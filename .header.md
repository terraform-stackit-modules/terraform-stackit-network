# Terraform STACKIT Network module

Terraform module which creates a [STACKIT network](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/network), with an optional security group and rules.

Designed for use with STACKIT virtual machines and managed databases.

## Usage

### Network only

```hcl
module "network" {
  source  = "terraform-stackit-modules/network/stackit"

  project_id  = "<project_id>"
  name        = "my-network"
  ipv4_prefix = "192.168.0.0/24"
}
```

### Network with security group

```hcl
module "network" {
  source  = "terraform-stackit-modules/network/stackit"

  project_id  = "<project_id>"
  name        = "my-network"
  ipv4_prefix = "10.0.1.0/24"

  create_security_group      = true
  security_group_description = "Allow SSH inbound and all TCP egress"

  security_group_rules = [
    {
      direction  = "ingress"
      ether_type = "IPv4"
      ip_range   = "0.0.0.0/0"
      protocol   = { name = "TCP" }
      port_range = { min = 22, max = 22 }
    },
    {
      direction  = "egress"
      ether_type = "IPv4"
      ip_range   = "0.0.0.0/0"
      protocol   = { name = "TCP" }
    },
    # Allow traffic from another security group
    {
      direction                = "ingress"
      ether_type               = "IPv4"
      remote_security_group_id = "<other_security_group_id>"
      protocol                 = { name = "TCP" }
      port_range               = { min = 5432, max = 5432 }
    },
    # Match by protocol number instead of name
    {
      direction  = "egress"
      ether_type = "IPv4"
      ip_range   = "0.0.0.0/0"
      protocol   = { number = 6 }
    },
  ]
}
```

## Notes

- Set `create_security_group = true` to have the module create a security group alongside the
  network.
- `security_group_rules` is a list of rule objects. A rule matches by `direction` (`ingress` /
  `egress`), by `protocol` (either `{ name = "TCP" }` or `{ number = 6 }`), and by `ip_range`
  or `remote_security_group_id`.
